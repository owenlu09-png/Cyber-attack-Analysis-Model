# Cyber-attack-Analysis-Model


Project Objective:
The objective of this project is to design and test an artificial intelligence 
system that can detect possible cyber attacks by analyzing audit events from a 
computer system or server. Audit events are records of actions such as login 
attempts, file access, permission changes, and unusual system activity. 
By training an AI model to recognize patterns in this data, the project will 
explore whether the model can distinguish normal system behavior from suspicious 
or malicious behavior. If successful, this system could later be adapted to run 
in real time on servers as an early warning tool for cyber threats.


Purpose of the Project:
Cyber attacks are often difficult to detect quickly because modern systems produce 
huge amounts of log and audit data. Human administrators may miss important warning 
signs buried inside thousands of normal events. This project aims to investigate whether 
AI can help automate that process by identifying attack-related patterns more efficiently. 
The broader purpose is to explore how machine learning could improve cybersecurity and server protection.
